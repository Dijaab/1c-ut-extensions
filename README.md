Набор расширений для типовой конфигурации Управление торговлей редакции 11.5, реализованный без снятия с поддержки.



Состав работы:



ДоработкаРеализации.cfe — расширение пользовательского интерфейса. Добавляет реквизит ПриоритетОтгрузки в документ РеализацияТоваровУслуг и выводит его на форму.



КонтрольЛимитаДолга.cfe — расширение серверной бизнес-логики. Реализует проверку задолженности клиента через подписку на событие и общий модуль, блокируя проведение документа при превышении лимита (Отказ = Истина).
